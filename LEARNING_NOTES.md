# Learning Notes

## 1. print()

### Code
print("Engineering Unit Converter")

### What does it do?

The print() function displays information on the screen.

In this project, I use it to display the title and instructions.

---

## 2. input()

### Code
choice = input("Choose a conversion (1-4): ")

### What does it do?

input() allows the user to type information.

The information the user enters is stored in the variable called
"choice".

---

## 3. Variables

### Code
miles = float(input("Enter miles: "))

### What does it do?

The variable "miles" stores the number entered by the user.

float() converts the user's input into a number that Python can
use for calculations.

---

## 4. Calculations

### Code
kilometers = miles * 1.60934

### What does it do?

This converts miles to kilometers.

The formula is:

kilometers = miles × 1.60934

---

## 5. if / elif / else

### What does it do?

These statements allow the program to make decisions based on
what the user chooses.

For example:

If the user chooses 1 → Miles to kilometers.

If the user chooses 2 → Inches to feet.

If the user chooses something else → Invalid selection.
